# AGIPC 粗层 PCG 分布分析

状态：2026-09-12，完成两次 16K、27 帧正常负载运行的逐 Newton 粗层求解离线统计。后校正残差保护的 27 帧复验仍等待 GPU 空闲，因此本文用于确定优化位置，不给出保护修正后的速度结论。

## 1. 数据与口径

分析使用以下两次已经完成的运行：

- `agipc_core_fig15_16k_stage_timing27_stats.json`：146 次方向求解，延迟细层预条件器优化之前；
- `agipc_core_fig15_16k_deferred_preconditioner27_stats.json`：99 次方向求解，延迟细层预条件器优化之后。

两次运行的 Newton 轨迹不同，因此不把总耗时相除作为加速比。`coarse_solve_ms` 包含粗层对角块提取、block-Jacobi PCG、延拓和一次细层真实残差复算。脚本 `analyze_coarse_pcg.py` 对每次求解提取粗块数、非零块数、迭代数、耗时、收敛结果和最终采用结果，并分别统计规模分箱、耗时集中度和相关性。

## 2. 总体分布

| 指标 | 阶段计时运行 | 延迟预条件器运行 |
|---|---:|---:|
| 方向求解次数 | 146 | 99 |
| 粗 PCG 总迭代 | 7,958 | 6,473 |
| 粗求解累计时间 | 1,180.342 ms | 965.852 ms |
| 单次耗时中位数 | 0.753 ms | 0.530 ms |
| 单次耗时 P90 | 31.573 ms | 38.010 ms |
| 迭代数中位数 | 4 | 2 |
| 迭代数 P90 | 195.5 | 230.8 |
| 迭代数与耗时相关系数 | 0.9954 | 0.9933 |
| 最大迭代数 | 512 | 512 |
| 最大单次耗时 | 74.106 ms | 78.451 ms |

两条轨迹中，每次粗 PCG 迭代折合的累计平均耗时分别为 `0.1483 ms` 和 `0.1492 ms`。尽管 `coarse_solve_ms` 还包含固定工作，其跨运行一致性和接近 1 的相关系数表明，当前主要变量是迭代次数。

## 3. 规模集中度

| 粗块规模 | 阶段计时：次数 / 时间占比 | 延迟预条件器：次数 / 时间占比 |
|---|---:|---:|
| 1–16 | 95 / 6.10% | 61 / 3.21% |
| 17–64 | 7 / 1.84% | 6 / 1.90% |
| 65–256 | 17 / 10.88% | 9 / 7.77% |
| 257–1024 | 9 / 16.51% | 3 / 5.82% |
| 1025 以上 | 18 / 64.67% | 20 / 81.31% |

超过 1024 个粗块的系统只占全部求解的 `12.3%` 和 `20.2%`，却消耗 `64.7%` 和 `81.3%` 的粗求解时间。相反，1–16 块的小系统占求解次数的 `65.1%` 和 `61.6%`，总耗时仅占 `6.1%` 和 `3.2%`。因此，为小系统改写直接解或削减固定启动开销不会触及主要耗时。

耗时还集中在极少数事件上：最慢 10 次分别占粗求解总时间的 `44.9%` 和 `55.6%`。这些事件集中在接触帧 27 的 Newton 尾部，粗系统通常含 1,600–9,370 个块，PCG 需要约 246–512 次迭代。

## 4. 采用结果与失败

阶段计时运行中，91 个最终采用的候选消耗 `1,048.612 ms`，占粗求解时间的 `88.8%`。54 个 `post_residual_not_reduced` 回退只消耗 `57.624 ms`；先前的冻结样本也证明它们主要是小粗系统的结果选择问题。后校正残差保护解决的是正确性和无效回退，并不是粗层 PCG 的主要性能来源。

延迟预条件器运行中，85 个采用候选消耗 `807.730 ms`，占 `83.6%`。两个达到 512 次上限的粗系统合计消耗 `152.154 ms`，占整个粗求解时间的 `15.8%`；其中最大系统含 9,370 个粗块。另有十个 `coarse_invalid_preconditioned_residual` 只消耗 `5.013 ms`，同样不是主要耗时。

## 5. 结论与下一步

当前 block-Jacobi 预条件器对小系统足够便宜，但大型接触系统的迭代数随粗块规模明显上升。`log(粗块数)` 与迭代数的相关系数为 `0.884` 和 `0.839`，而迭代数几乎直接决定耗时。下一项代码工作应针对大型粗系统增强预条件器，而不是继续微调后校正步数或小系统启动成本。

论文主性能路径使用 MAS，当前粗层 block-Jacobi 仍是中间实现。为了在不改变非线性轨迹的前提下比较预条件器，下一次显式诊断运行应冻结至少一个 257–1024 块、一个 1025 块以上和一个达到迭代上限的粗系统，保存 `Hc/gc` 与当前解。随后在冻结系统上比较 block-Jacobi 与粗层 MAS 的迭代数、真实残差和方向下降量，通过后再接入运行时。
