# AGIPC 逐帧检查点与首次非线性分叉

日期：2026-09-15

## 结论

当前机器环境没有达到性能结论门槛。本轮开始前单点 GPU 利用率为 33%；随后 10 秒采样为 10%–63%、中位数 29%，显存活动中位数 18%、占用约 1,246 MiB，P-state 在 P5/P8 间切换，图形时钟 300–450 MHz。系统还有多个 WDDM/计算进程无法可靠归属。项目约定还要求预热、StiffGIPC/AGIPC 交错运行、每种方法至少 3 次测量、相同物理轨迹和中位数/离散程度；本地场景仍是缩放复现资产，硬件也是 RTX 3070 Laptop 而非论文 RTX 4090。因此不能开启本地受控速度比或论文定量性能结论。

本轮转而完成数值分叉定位。新增显式 `--fem-checkpoint-path`，只在完整 headless 诊断中按起始帧和步长保存 FEM 全顶点 FP64 状态。初始态加第25–35帧共12条记录，每方法仅4,792,608字节。检查点标记 `performance_claim=false`，这两次运行不进入性能样本。

同一新可执行文件下的35帧 AGIPC block-Jacobi 与 MAS32+复用均完成、顶点有限、地面穿透为零。两者在第25/26帧仍只有约 `4e-9` 的绝对 RMS 差；第27帧升至 `2.419e-4`，第28帧超过 `1e-3`，第30帧相对 RMS 超过1%，第35帧达到2.1337%。Newton 记录把第一个离散分叉定位到第27帧 Newton 2 / Galerkin update56：保护边从 `4312/4313` 分开，粗节点从 `1317/1319` 分开。

## 实现与门槛

新增参数：

```text
--fem-checkpoint-path <BINARY_PATH>
--fem-checkpoint-start-frame <N>
--fem-checkpoint-stride <N>
```

二进制布局为 frame-major、vertex-major、XYZ FP64，配套同名 JSON 保存格式、帧号、节点数、字节数以及每帧报告的 Newton/PCG 迭代和末端接触对数量。record0 始终是初始 FEM 状态，便于计算相对位移误差。检查点只允许完整 headless 运行，和 frozen-linear/direction-freeze 互斥；非法非 headless 调用在场景初始化前 exit2。

`compare_frame_checkpoints.py` 独立检查格式、长度、有限性、初始状态一致性，并计算每帧全节点 RMS、相对 RMS、最大逐点误差和首次越过门槛的位置。提供两份 `stats.json` 时，它还对齐 Newton 记录，报告首个保护边、粗节点和已应用候选采用分叉。

Release 构建 exit0，`--agipc-self-test` exit0/`passed=true`，单帧检查点 smoke exit0、结构/自比较门通过且误差为0。新可执行文件 SHA-256 为 `AF1700CEF3112A0F31352D8324390E5D0986FDDC80C604C8C998DA95503E2935`。输入布料保持 `2B2F1EE3279DD38EE778694AEC5386A101C77EAE7F1A18D020C9E9AB816017F8`。

## 第27帧分叉机制

| Newton / update | 方向范数相对差 | 保护边 J/M | 粗节点 J/M | 采用步长 J/M |
|---:|---:|---:|---:|---:|
| 0 / 54 | `1.862e-8` | 0 / 0 | 1 / 1 | 0.184707483 / 0.184707344 |
| 1 / 55 | `1.247e-4` | 0 / 0 | 1 / 1 | 0.139526059 / 0.139524845 |
| 2 / 56 | `1.17884%` | 4,312 / 4,313 | 1,317 / 1,319 | 0.312793758 / 0.323828231 |
| 3 / 57 | `0.50229%` | 3,434 / 4,356 | 708 / 872 | 0.856089992 / 1.0 |

Newton 0和1均无保护边且只产生一个平面仿射聚合组；两种粗预条件器都采用候选。Newton 1 的方向范数已出现约0.0125%差异，但后校正最终残差仍非常接近：`4.4261e-4/4.4272e-4`。执行这一步后，Newton 2 有一条边落在阈值两侧，粗映射差2个节点，方向范数和线搜索步长立即拉开。到Newton 3，保护边差922条、粗节点差164，Jacobi被CCD/线搜索限制到0.856而MAS取完整步长。首个“已应用候选采用/回退不同”直到第28帧 Newton 9才出现，因此采用门不是第27帧分叉的起点。

这支持一个更具体的解释：两种迭代粗解产生很小的连续方向差；接触开始后，固定硬阈值把它转化为离散边标签差，再经层级映射和线搜索放大。它没有证明任一预条件器计算错误，也没有证明修改阈值会提高物理精度。论文自己把固定 Green 阈值列为限制，本地证据说明这一限制在当前缩放 Figure15 状态中确实活跃。
