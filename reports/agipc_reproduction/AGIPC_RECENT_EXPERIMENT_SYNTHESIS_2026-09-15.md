# AGIPC 近期实验数据与阶段性分析

日期：2026-09-15
范围：accepted-direction 独立参考、Green 判据快照、逐帧首次分叉、单次预备性能配对。

## 当前结论

AGIPC-Core 的已测基础算术没有发现错误：混合 Galerkin 装配、GPU/CPU 后校正、当前 Green 张量和全部边标签都通过独立回放。当前主要问题已经收敛为两个相互关联的现象：粗空间加有限 post10 在接触系统上可能给出较弱方向；小的方向差在固定 Green 硬阈值附近会变成离散标签和映射差，并在后续 Newton/线搜索中放大。

2026-09-15 的一次预备性能配对中，AGIPC-Core MAS32 用更少的 Newton 更新完成35帧，但观测模拟耗时仍为 StiffGIPC 的1.2207倍，每个已应用 Newton 的成本为1.8334倍。AGIPC内部粗层求解累计28.179秒，是最大单项。同时终态相对 RMS 差为3.5029%，数值等价也未通过。

这不是正式速度结论。两次测量前GPU利用率中位数分别为24%和36%，方法顺序固定且只有一对样本；硬件和缩放资产也不匹配论文。当前可陈述的结果是：**这一次负载失控的本地测试中，AGIPC慢22.07%，且方向/轨迹差异仍然显著。**

## 1. Accepted-direction 独立参考

首个冻结样本使用完整细层 H/g、粗矩阵、映射、粗解、延拓方向和实际采用方向。对称 SparseLU、独立 Galerkin 重建和CPU post10/20门均通过：GPU10与CPU10方向相对差为`6.22e-15`，说明已测GPU后校正没有计算偏差。

| 方向 | 欧氏误差 | H能量误差 | 相对细直接解预测下降 |
|---|---:|---:|---:|
| 精确粗层解延拓 | 99.7576% | 99.0453% | 1.9003% |
| GPU10 / CPU10 | 98.3341% | 95.1323% | 9.4985% |
| CPU20消融 | 93.7257% | 88.3400% | 21.9605% |

该样本中6个仿射组覆盖98.35%的FEM节点，当前粗空间对细直接方向的最佳欧氏拟合误差仍为93.87%。精确粗解也不能改善，主要损失来自粗空间表达能力，而非粗PCG精度。

第二次判据捕获形成了不同H/g和映射，GPU10方向误差为87.55%、保留46.40%预测下降。这说明相同“update300”不是跨运行可比较的确定状态，也说明方向质量随非线性状态显著变化。

详细报告：`AGIPC_ACCEPTED_DIRECTION_QUALITY.md`。

## 2. Green 判据与层级映射

显式快照保存元素几何、当前Green张量/增量、边—单元邻接、边标签/原因、边界、当前FEM位置。独立CPU重建得到：

| 检查 | 结果 |
|---|---:|
| 当前Green最大相对误差 | `8.2003e-15` |
| 原因位不一致 | 0 / 49,408 |
| 标签不一致 | 0 / 49,408 |
| 保护边 | 12,485（25.2692%） |
| 无效元素 | 0 |

默认阈值`5e-5`下，全局允许边图有1,958个连通分量，最大分量包含14,379个节点。运行时32-lane递归warp-hash停在2,202组，最大组1,031节点，并保留2,193条允许跨组边。运行时稳定分组的最佳方向拟合误差为62.86%，强制全局连通合并则为84.96%，所以没有证据支持用union-find替换论文映射。

同一增量场的离线扫描显示：阈值从`2.5e-5`升至`5e-5`时，全局连通参考的活跃FEM块比例从48.98%降到11.78%，最大分量覆盖从14.02%升到86.41%，最佳方向拟合误差从44.45%升到84.96%。论文默认阈值正处在本样本的连通跃迁区。

详细报告：`AGIPC_CRITERION_SNAPSHOT_ANALYSIS.md`。

## 3. 首次非线性分叉

同一可执行文件的AGIPC block-Jacobi与MAS32+复用路线保存共同初始态及第25–35帧完整FEM状态。第25/26帧绝对RMS差仍低于`4.7e-9`；接触开始后迅速增加：

| 帧 | 绝对RMS差 | 相对RMS差 | 最大逐点差 |
|---:|---:|---:|---:|
| 25 | `4.159e-9` | `1.306e-6%` | `6.237e-9` |
| 26 | `4.622e-9` | `1.344e-6%` | `6.932e-9` |
| 27 | `2.419e-4` | 0.06537% | `2.124e-3` |
| 28 | `1.846e-3` | 0.46592% | `7.889e-3` |
| 30 | `4.791e-3` | 1.06947% | `2.055e-2` |
| 35 | `1.238e-2` | 2.13368% | `4.736e-2` |

第27帧内部的首个离散变化：

| Newton / update | 方向范数相对差 | 保护边 J/M | 粗节点 J/M | 接受步长 J/M |
|---:|---:|---:|---:|---:|
| 0 / 54 | `1.862e-8` | 0 / 0 | 1 / 1 | 0.184707483 / 0.184707344 |
| 1 / 55 | `1.247e-4` | 0 / 0 | 1 / 1 | 0.139526059 / 0.139524845 |
| 2 / 56 | 1.17884% | 4,312 / 4,313 | 1,317 / 1,319 | 0.312793758 / 0.323828231 |
| 3 / 57 | 0.50229% | 3,434 / 4,356 | 708 / 872 | 0.856089992 / 1.0 |

首个已应用采用/回退差异直到第28帧Newton9才出现。因此最早机制不是采用门，而是两种有限迭代粗解的微小方向差在接触时跨过一条Green硬阈值，随后经层级映射和线搜索放大。

详细报告：`AGIPC_FRAME_CHECKPOINT_DIVERGENCE.md`。

## 4. 2026-09-15 单次预备性能配对

### 配置

- 场景：`paper-fig15-cloth-abd-scaled`
- FEM布料：16,641节点、32,768三角形
- 固定ABD障碍，`E=1e6`，`dt=.01`
- 框架：`abd-cemas-srbk`
- 两路线均使用`paper-current` Newton停止语义
- StiffGIPC：原细层求解
- AGIPC-Core：阈值`5e-5`、warp-hash、MAS32、GPU局部检查、精确结构复用、post10
- 各完成一次1帧预热，再固定顺序运行StiffGIPC后AGIPC；35帧测量没有检查点或冻结写盘

可执行文件SHA-256：`AF1700CEF3112A0F31352D8324390E5D0986FDDC80C604C8C998DA95503E2935`
网格SHA-256：`2B2F1EE3279DD38EE778694AEC5386A101C77EAE7F1A18D020C9E9AB816017F8`

配置一致性门通过；两路线均完成35帧、顶点有限、地面穿透为0。

### 总体结果

| 指标 | StiffGIPC | AGIPC-Core | AGIPC / Stiff |
|---|---:|---:|---:|
| 模拟计时 | 41.1049 s | 50.1772 s | **1.2207** |
| 每帧 | 1.17443 s | 1.43363 s | 1.2207 |
| 已应用Newton | 784 | 522 | 0.6658 |
| 每Newton | 52.4297 ms | 96.1249 ms | **1.8334** |
| 报告线性迭代 | 56,727 | 82,060 | 1.4466 |
| 最大自碰撞对 | 193 | 209 | — |

本次AGIPC少262次Newton，但每Newton多约43.70 ms，最终总计慢9.072秒。StiffGIPC最重帧为第28帧206步、第33帧105步、第27帧101步；AGIPC最重帧为第31帧101步、第33帧75步、第32帧66步。两条路线的工作分布明显不同。

AGIPC有557次候选尝试、555次采用、2次回退；回退原因为1次映射层级上限和1次粗迭代上限。残差保护恢复8次，MAS本地失败0次，结构复用56次。高采用率仍没有转化为低总成本。

### AGIPC内部成本

| 阶段 | 累计耗时 | 每556次更新平均 | 占AGIPC模拟计时 |
|---|---:|---:|---:|
| Galerkin装配 | 1.7863 s | 3.213 ms | 3.56% |
| 粗层求解 | **28.1791 s** | **50.682 ms** | **56.16%** |
| post10 | 1.3774 s | 2.477 ms | 2.74% |
| 完整自适应管线 | 31.3848 s | 56.447 ms | 62.55% |
| 判据映射 | 1.1997 s | 2.155 ms | 2.39% |

这些是当前实现CUDA事件区间，用于定位成本。事件同步、外部负载和不同轨迹使它们不适合作为论文阶段占比复现，但粗层求解远高于装配/post10的结论很明确。

### 终态差异

| 指标 | 结果 |
|---|---:|
| 16,641节点终态RMS差 | `0.0203309` |
| 相对StiffGIPC RMS位移 | **3.50287%** |
| 最大逐点差 | `0.0768556` |
| Stiff/AGIPC RMS位移 | `0.580408 / 0.580146` |
| Stiff/AGIPC FEM最小y | `-0.324950 / -0.329431` |

终态差异比近期Jacobi/MAS检查点对照的2.13368%更大。不同求解器轨迹不能用总耗时直接解释为“同一计算更快/更慢”，也没有通过数值等价门。

### 性能环境

| 运行前5秒 | GPU利用率最小/中位/最大 | 最高温度 | P-state |
|---|---:|---:|---|
| StiffGIPC | 7% / 24% / 33% | 47°C | P0/P5/P8 |
| AGIPC-Core | 25% / 36% / 39% | 49°C | P3/P5 |

Stiff运行后GPU仍为76%；额外30秒冷却采样中位数25%、峰值51%，没有达到连续3次≤10%的目标。AGIPC因此在更高的预运行负载下开始。固定顺序、单样本和不同初始负载足以否定正式速度比。观测1.2207只作为负面原始结果保留。

## 综合判断

| 问题 | 当前证据 |
|---|---|
| Green判据是否算错 | 已测样本不支持；张量与全部标签独立通过 |
| Galerkin/后校正是否算错 | 已测样本不支持；独立装配和GPU/CPU方向通过 |
| 粗方向是否始终足够好 | 否；两个冻结样本分别只有9.50%和46.40%预测下降 |
| 固定阈值是否会放大微小差异 | 是；第27帧已定位一条边的首次翻转及后续映射放大 |
| 当前AGIPC是否比基线快 | 本次没有；观测慢22.07%，且性能门失败 |
| 当前长接触状态是否数值等价 | 没有；本次相对RMS差3.50% |
| 是否可以开始论文性能结论 | 不可以；资产、硬件、负载、重复次数和数值门均未满足 |

## 下一步

1. 在第27帧update55/56附近冻结一个系统，并让Jacobi与MAS在完全相同的H/g、映射和初值上同时重放粗解、延拓和post10；计算两条方向及预测下降差。
2. 对该快照导出阈值附近的最小边裕量和对应单元，验证一条边翻转是否确实由有限迭代方向差触发。
3. 数值机制确认后再处理粗层成本。当前最高收益方向是MAS设置/求解路径，而不是进一步压缩Galerkin装配或增加post步数。
4. 正式性能实验等待GPU低负载，使用无检查点/冻结参数，至少3次交错测量并报告中位数、标准差、CV和完整哈希；本地结果与论文RTX4090结果分开表述。
